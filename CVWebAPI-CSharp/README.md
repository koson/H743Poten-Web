# C# CV Web API

ASP.NET Core-based Cyclic Voltammetry Web API with real-time data streaming.

## Features
- Real-time CV data acquisition (10 Hz)
- DMM integration (Keysight 34461A)
- System performance monitoring
- RESTful API
- Chart.js visualization
